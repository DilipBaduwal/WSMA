# WSMA

A Hindi movie discovery and community recommendation site. It shows recent and popular Hindi films, TMDB artwork and metadata, locally generated editorial guidance, streaming availability, and community watch votes.

## Requirements

- Node.js 18 or newer
- A TMDB API key or API Read Access Token
- Optional: Tavily API key for editorial research
- Optional: Ollama with `qwen2.5:3b` for locally generated editorial notes

## Configure

Copy `.env.example` to `.env` and add your server-side API credentials:

```env
TMDB_API_KEY=your_tmdb_api_key
TAVILY_API_KEY=your_tavily_api_key
QWEN_MODEL=qwen2.5:3b
```

You can use `TMDB_ACCESS_TOKEN` instead of `TMDB_API_KEY`. Keep `.env` private; it is excluded from Git.

## Run locally

```sh
node server.js
```

Open [http://localhost:3000](http://localhost:3000). The catalogue refreshes daily and is cached locally.

The site uses TMDB for movie metadata, ratings, posters, backdrops, and Indian streaming availability. It is not endorsed or certified by TMDB. Poster and backdrop images are loaded from TMDB; the site does not copy artwork from research articles.

## Data files

- `content-cache.json` is generated by the server and should not be committed.
- `visitors.json` and `community-votes.json` contain local analytics and community votes and should not be committed.
